# Sample briefs

`data_governance_ai_public_sector.md` and the matching `.docx` show the
output format the tool produces — a title, executive summary, background,
key findings, policy implications, recommendations, sources, and
limitations, in UN/UNDP style.

These two are **hand-written illustrative examples**, not the output of a
live `/generate` call against a real source. They exist to show the shape
and tone of a brief without requiring an LLM API key to inspect one. The
`.docx` was produced by feeding this same content through the real
`templates.word_export.build_docx()` — so its formatting (headings, bullet
findings, numbered recommendations) matches exactly what a live-generated
brief would look like once exported.
